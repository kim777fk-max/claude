# 領収書 → マネーフォワードに仕訳（公式MCP連携）

Claude に領収書（写真/PDF）を渡すと、中身を読み取ってマネーフォワード クラウドに**仕訳／入出金明細を自動登録**できます。
2026年3月26日に提供開始された**公式リモートMCPサーバー**を使うため、こちら側にサーバーを立てる必要はなく、**接続設定だけ**で動きます。

```
領収書（写真/PDF）を Claude に渡す
   → Claude が 日付・金額・店名・用途 を読み取り
   → MCP経由で MoneyForward に仕訳を登録（税込→本体+消費税に自動分解）
```

## 前提の確認（最初にここだけ）

- 対象は「クラウド会計・確定申告」。パーソナルプラン（個人事業主向け確定申告）が使えるかは、下記アプリポータルで
  **「アプリ連携」を有効化できるか**で判断できます（有効化できれば利用可）。
- アプリポータルで管理者権限が必要です。

## セットアップ手順

### 1. アプリポータルで連携を許可（最重要）

1. https://app-portal.moneyforward.com/ にログイン
2. ユーザー設定で自分のアカウントを編集
3. **「アプリ連携」** のチェックを ON
4. 連携範囲で以下を許可：
   - 事業者情報
   - クラウド会計・確定申告

### 2. Claude 側にMCPサーバーを登録

リモートMCPエンドポイント（Beta = 自動再認証あり・推奨）：

```
https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3
```

- **Claude Code（ローカル）**：プロジェクト直下に `.mcp.json` を置く

  ```json
  {
    "mcpServers": {
      "mfc_ca": {
        "type": "http",
        "url": "https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3"
      }
    }
  }
  ```

  ※ `"type": "http"` は必須。省くとサーバーが認識されません。

- **Claude Desktop / Cowork（アプリ）**：コネクタ設定から上記URLをリモートMCPとして追加。

### 3. 認証（OAuth）

1. Claude Code なら `/mcp` → `mfc_ca` → 「Authenticate」
2. ブラウザでマネーフォワードのログイン画面が開く
3. 要求されるスコープを承認
4. 約1分で接続完了

## 使える操作（全17ツール）

- **読み取り（12）**：事業者情報・会計期間・勘定科目・税区分・取引先・部門・仕訳一覧・残高試算表・推移表 など
- **書き込み（5）**：仕訳の作成／更新、取引先の一括作成、入出金明細（銀行照合）データ

**領収書→仕訳のポイント**：税込金額（例 ¥1,000）を渡すと、本体（¥910）＋消費税（¥90）に**自動分解**して登録。Claude側で税計算する必要はありません。

## 日々の使い方

1. 領収書を撮る／PDFを用意
2. Claude セッションに渡して「これ仕訳にして登録して」と伝える
3. Claude が勘定科目・税区分を判断し、MFに仕訳を登録
4. 迷う勘定科目は確認してから登録（承認フロー的に運用可）

# 毎朝の自動反映＋分析（デイリールーティン設計）

「毎朝1回、Claude Code が MoneyForward を見に行き、内容を index.html（＝Supabase）に反映し、
資金繰りを分析。ユーザーは朝アプリを開いて確認する」フローの設計。

## パイプライン

```
毎朝 07:00（例）Claude Code のスケジュール実行が起動
   1. MF MCP で前日までの入出金明細・仕訳・残高を取得
   2. このアプリの Supabase(expense_transactions) に upsert（external_id で重複防止）
        → index.html に自動反映（ユーザーは開くだけ）
   3. 資金繰り分析を生成：
        ・現在残高／月末残高予測／最低残高とショート予測
        ・予算超過・未取込の定期・異常な支出の検知
   4. 「今朝のブリーフィング」をアプリ内 or 通知（Discord/メール）に出力
   5. ユーザーは朝、アプリで確認
```

## 実現性と関門

| 要素 | 実現性 |
|------|--------|
| 毎朝の自動起動 | ✅ Claude Code（web）のスケジュール実行／トリガーで可能 |
| MFからデータ取得 | ✅ 公式MCP（仕訳一覧・入出金明細・残高試算表） |
| アプリへ反映 | ✅ Supabase に直接書き込み（キー認証でheadless向き） |
| 分析・通知 | ✅ ブリーフィング生成＋Discord/メール送信 |
| **無人でのMF認証** | ⚠ **最大の関門**。MCPはOAuthログイン。スケジュール実行（headless）で
  トークンが切れると再認証が必要になり得る。Betaエンドポイントは自動再認証を謳うが**要検証**。 |

## 関門への対処

- まず対話セッションで MF MCP 接続を確立し、**スケジュール実行でトークンが維持されるか実測**する。
- 維持できない場合の代替：
  - **半自動**：毎朝のセッションが分析まで準備し、MF認証だけ**ワンタップ承認**（通知から）。
  - CSVブリッジ：MFのエクスポートを定期的に取込（完全自動ではないが確実）。

## 段取り

1. MF側で「アプリ連携」ON＋一度OAuth認証（上のセットアップ手順）
2. 対話セッションで「MF→Supabase反映＋分析」を手動実行し、動作確認
3. スケジュール実行（cron/トリガー）に載せる
4. headless認証の可否で「完全自動」か「毎朝ワンタップ」かを確定
5. アプリ内に「今朝のブリーフィング」枠を追加（landing先）
