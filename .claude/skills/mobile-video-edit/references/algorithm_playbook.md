# アルゴリズム正典（クラウド版・2026-07-04 引き継ぎ）

出典: Mac側動画編集セッションの引き継ぎ書（auto-cut / social-clip スキル構築・アルゴリズム調査組込済み）。
Mac正本: `~/.claude/skills/auto-cut/references/algorithm_playbook.md`（出典付き）。
この写しはクラウドセッション用。編集プラン・テロップ案・EDL作成はこの文書だけで判断できる。

## 1. 配信の共通5原則（2026-07調査・YouTube/X/Instagram）

1. **満足度 > 視聴時間**。引き伸ばし・釣りテロップは全プラットフォームで降格
   （Xの旧公式コードは通報-369点。YouTubeはCTR高×30秒離脱の複合で配信抑制）。
2. **冒頭2〜3秒が分水嶺**。Xは「2秒視聴」でカウント成立（公式定義）・Instagramは約1.7秒で
   見る/送るを判断・Shortsは「スワイプされなかった率」が中核指標。
   → **ロゴ・黒フェード・タイトルカード単体での開始は禁止。本編の動きのあるフレームで開始（fade=0）**。
3. **短尺はループが最強**。リプレイは視聴時間に加算、平均再生率100%超は強い推薦シグナル。
   ループは **7〜15秒・終端の絵≒冒頭の絵**。
4. **テロップはSEO資産**。InstagramはOCR（Rosetta）で画面内テキストを読んで分類・検索に使う。
   ミュート自動再生（X公式仕様）前提で音がなくても意味が通ること。
   **冒頭テロップに「検索されたい語」を1語入れる**。
5. **いいねを乞わない**。効くのは一段深いシグナル: X=リプライ（いいねの27倍・旧公式コード）／
   Instagram=DMシェア（sends per reach・Mosseri公式）と保存／YouTube=コメント誘発。
   「いいねしてね」はIGでベイト降格リスク。

## 2. 配信先プリセット表（EDL設計はこの行に従う）

| 配信先 | 伸びる尺 | 冒頭fade | ループ | 終端のCTAテロップ |
|---|---|---|---|---|
| YouTube長尺 | 価値が続く限り | 0.5可 | — | 登録CTAは尺の**55-75%**地点・**ラスト15-20秒はエンドスクリーン余白**（静かな絵で残す） |
| YouTube Shorts | **20-45秒** | **0** | 7-15秒 | コメント誘発の質問 |
| Instagram Reels | **7-15秒**（How-to 30-60）・90秒超NG | **0** | 7-15秒 | 「誰かに送りたくなる」一言 |
| TikTok | 15-60秒 | **0** | 推奨 | 同上 |
| X | **20-45秒**（無料上限140秒/512MB） | 0〜0.2 | 短尺なら有効 | **質問テロップ**（リプライ誘発）。リンクは本文でなくリプライ欄・タグ0-2個 |

補足: ShortsとYouTube長尺はアルゴリズム分離済み（別ルールで作る）／Xには2025年から9:16の
縦型ビデオタブがある＝**Xも9:16を出す価値あり**（16:9と2枚出しが理想）／Instagramの
プロフィールグリッドは3:4クロップ＝4:5投稿の文字・顔は中央約1012px幅に。

## 3. カット割りのルーブリック（区間選定は感覚でなく採点）

候補区間を**5軸×0-2点**で採点。**採用=7点以上／保留=5-6（尺不足時のみ）／捨てる=4以下**。

| 軸 | 0点 | 2点 |
|---|---|---|
| 動き | 静止・放置録画 | 被写体が動く/変化の瞬間（点火・投げる・注ぐ） |
| 光 | 白飛び/黒潰れ | マジックアワー/印象的な光 |
| 構図 | 地面/壁だけ | 主役明確・前景背景の層 |
| 物語 | 文脈なし | 導入/山場/オチのどれかを担える |
| 独自性 | 重複テイクの余り | この絵はここだけ |

- **冒頭（1カット目）だけは基準を1段甘く**: 6点でも「動き」か「光」が2点なら採用可
  （離脱の大半は冒頭で起きるため、目を引く一瞬を最優先）。
- 各区間4〜10秒（ショートは2〜5秒）。手かぶり・激ブレ・重複テイクは点数に関係なく捨てる。
- カット密度: 縦短尺は**10秒に5〜7回の視覚変化**（4回未満=間延び・8回超=うるさい）。
  横ロングは20〜40秒に1回のB-roll切替、感情のピークは逆に3〜4秒ホールド。

## 4. テロップのコピー規則

- **1行13文字以内・最大2行・表示2秒以上**・前後の間隔0.5秒以上・60秒に4〜8枚
- **読み速度=文字数÷表示秒 は7文字/秒以内**（12超は誰も読めない）
- **見えている物の名前を言わない**。気持ち・文脈・情報のどれかを足す:

| ✗ ダメ | ○ 良い |
|---|---|
| ランタンです | 初点火、ちょっと緊張 |
| 夕日がきれい | この瞬間のための儀式 |
| 子供が遊んでいる | 設営そっちのけでバドミントン |
| 薪です | 薪1000円詰め放題の戦利品 |

- 語尾は体言止め or 短い口語。絵文字の多用はしない。
  冒頭タイトル=動画の看板／本編テロップ=各カットの一言（役割を混ぜない）。
- 縦9:16のテロップは**中央900×1400pxのセーフゾーン内**（下から28%・幅80%が既定）
  ＝各アプリのUIと被らない。

## 5. 投稿後に見る数字（改善ループの観測項目）

| 配信先 | 指標 | 合格ライン | 不合格時 |
|---|---|---|---|
| YouTube長尺 | CTR / 30秒リテンション | 2-10%帯 / 70% | CTR低→サムネ・タイトル、リテンション低→冒頭15秒差し替え |
| Shorts | viewed%（スワイプされなかった率）/ 平均再生率 | 70% / 100%超=ループ成功 | 冒頭1-2秒差し替え |
| Reels | Skip Rate（公式指標）/ sends per reach | <40% / 上昇 | フック改修・Trial Reelsで別フックをA/B |
| X | 25%到達率 / リプライ数 | 30%以上 | 冒頭2秒差し替え・終端の質問変更 |

## 6. Mac側の実行資産（クラウドから依頼する時）

| スキル | 役割 | 発動ワード |
|---|---|---|
| **auto-cut** | 素材→区間選定→テロップ→1本のmp4 | 「自動でカットして」「ラフカット作って」＋素材パス |
| **social-clip** | 1本のクリップ→9:16/1:1/16:9/4:5整形・BGM・ループ | 「ショート用に縦にして」「Xに投稿する動画にして」 |
| **footage-triage** | 大量素材の選別（keep/cutのHTML表） | 「素材を仕分けて」＋フォルダパス |

- 全部ffmpegのみ＝課金ゼロ。§1のルールはMacスキル側に組込済み（配信先を言うだけで効く）。
- 素材のMacへの送り方: Claude Inbox（Tailscale限定・URLは本人既知・30日で自動削除）or AirDrop。
- 実行手段: iPhoneからccm（SSH+mosh+tmux）or Macの前でMac側セッションへ。

**EDL（カット指示JSON）をクラウドで書いてMacに渡す形**:
```json
{
  "target": {"w": 1080, "h": 1920, "fps": 30},
  "fade": 0, "loop": true,
  "captions": [
    {"range": 0, "rel": 1.0, "dur": 3.0, "text": "初点火、ちょっと緊張"}
  ],
  "ranges": [
    {"src": "<素材の絶対パス>", "in": 6.0, "out": 12.0},
    {"src": "<素材の絶対パス>", "in": 90.0, "out": 96.0}
  ]
}
```
（テロップはrange内の相対秒＝時刻の暗算不要。Mac側 validate_edl.py が文字数/表示秒/尺帯/フェードを機械チェック）

## 7. スマホ素材の落とし穴（実証済み）

- **iPhone縦動画が横倒しで紛れる**ことがある（要回転確認＝フレームを1枚見る。真上撮りは
  判定不能なのでユーザーに確認）／Live Photos（2-3秒動画）は素材外／同名「-1」「-2」コピーは重複
- **カメラ間の時刻ソートは不可**（GoPro時計未設定・iPhoneは書出時刻になる）
  → 各カメラ内はファイル名連番順・カメラ間は内容で並べる
- 巨大素材（8GB/20分級）もfast-seek対応済み／HEIC写真も読める
- **TikTokアプリ書き出し（ロゴ透かし入り）をReelsに使い回さない**（おすすめ面で降格・自分のロゴはOK）

## 8. 鉄則

- **課金ゼロ設計を崩さない**: 有料API系（音声合成課金・動画生成課金）は本人の明示指示がある時だけ
- YouTubeへのアップは**本人がローカル確認後のみ**（自動アップ禁止）
- 数値の多く（離脱率・最適尺等）はSaaSベンダー実測＝**固定値でなく目安**。
  公式確認済み: X視聴カウント=2秒・X旧コードの重み・IG3大シグナル・IGハッシュタグ無効・
  Shorts/長尺の分離・YouTubeエンドスクリーン枠5-20秒
