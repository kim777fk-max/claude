# v2（pro テーマ）設計記録

ベースライン `composition/`（v1・明るい生成り基調）は変更せず保存。v2 は Mac 正典資料
（character-explainer-video の design-system / theme.ts の pro、design-deck の design_philosophy）を
クラウドへ移した設計ルールで作り直した別バージョン。

## テーマを pro にした理由（v1 との比較）
| 観点 | v1（生成り＋青） | v2（pro：紺＋アンバー） | 判断 |
|---|---|---|---|
| 用途→テーマ | 汎用の解説トーン | 「診断士・経営者・顧客向け提案は pro か minimal に固定」 | 業務改善の構想提案なので pro が方針に合う |
| アクセント | 青1色のみ | アンバー主、情報=青、完了=緑、夜間=紫を場面ごとに回す | 「全部 accent 一色にしない」ルールへ対応 |
| 配置 | 3場面とも左テキスト＋右カード | S1 左寄せ／S2 左右反転／S3 中央の時間軸 | 「同じ構図を連続させない」ルールへ対応 |
| 文字量 | 見出し＋補足文 | 見出し1つ＋図（補足文は削除） | 一場面一メッセージ |
| フォント | Noto Sans JP のみ（ビルド時に取得） | 見出し Zen Kaku Gothic New 900／本文 Noto Sans JP／数字 JetBrains Mono。サブセット woff2 を同梱 | pro の font トークン、かつクラウド側に同梱という要件 |

v1 に残す価値: 明るい画面が合う用途（社内掲示・印刷）では v1 のほうが読みやすい。

## pro トークンを 1280×720 用に換算（×2/3）
safe 120→80px、gap 48→32px、cardPad 56→37px、radius sm/md/lg 8/14/20→5/9/13px、shadow md は 0 12 36→0 8 24。
色の値は theme.ts のまま。ただし次の2点は理由があって変えた。
- **背景**: theme の `bgGrad`（135°の全面リニアグラデ）ではなく、単色 `#0C1C2E`＋`#143350` の放射グロー。
  HyperFrames の video-composition 規則「暗い背景に全面リニアグラデは H.264 で縞が出る」に従った。
- **青い文字**: `info #3E8FE0` は紺背景だとコントラストが 3.7〜4.3 で、AA の 4.5 に届かない。
  文字だけ pro 内の `code.func #6FB6E8` を使い、点・線・枠は `#3E8FE0` のまま。

## 事実の扱い
- 画面は常に「構想段階｜実在のサービスではありません」。チャットに「表示は架空の例」、結果に「（例）」、締めに「※ 構想・例示です」を入れる。
- 送信者・文面・件数はすべて架空。実績数値やグラフは入れない。
- HeyGen アバター（診断さん）は **この版には登場しない**。音声もなし（無音）。

## フォント同梱
`assets/fonts/*.woff2` は Google Fonts CSS2 API の `text=` で、使う文字（`SUBSET_CHARS.txt`）だけに絞った
サブセット（合計 約166KB）。ライセンスは OFL 1.1（`LICENSE-*.txt`）。
**文言を変えたら、サブセットを取り直すこと**。取り直さないと、足りない字が代わりのフォントで描かれる。
